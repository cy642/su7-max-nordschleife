**线上试驾**　车库点击「线上试驾」，选择机场性能测试或公路自由试驾，再点击开始。机场用平直跑道测加速，冲过 400 米线后，在 600 米黄框内停稳。自由试驾使用所选赛道，可以无对手连续绕圈，在「试驾菜单」结束行程并查看报告。每个场地分别记录每款车的成绩，可比较零百加速、100–0 km/h 刹停距离和最高车速。试驾中可以切换视角、灯光和鸣笛，SU7 Max 还可以手动升降尾翼。

第一代 SU7 标准版采用后驱调校，Max 配电动尾翼。YU7 GT 的 SUV 车身与驾驶视点更高，Ultra 采用固定大尾翼和赛道套件。Vision GT 按小米展示的概念车单独建模，零百与极速使用游戏设定。车库量产车参数引用厂商资料，赛道成绩取决于驾驶操作和游戏物理。

### 新增玩法（2.0 升级）

- **巡回锦标赛 & 九城大满贯**：提供「五站经典巡回」与「九城大满贯（全部 9 条赛道）」双杯赛积分制（10 / 8 / 6 / 5 / 4 / 3 分），进度按杯赛、车型与难度独立保存。
- **漂移大师 & 漂移氮气充能**：全新「漂移大师」模式挑战目标漂移分；在任意赛事中干净起漂连击（最高 ×5.0）不仅伴随 3D 轮胎白烟特效，结算后还能同步缩短一键 Boost 冷却时间。
- **动态天气与时段**：支持 **晴朗 / 黄昏 / 暴雨 / 浓雾** 切换。暴雨自带 3D 动态雨丝粒子、雨声氛围与真实湿地抓地/刹车衰减，夜间与雨天自动点亮车灯（随时按 `L` 开关）。
- **车漆涂装 & 底盘调校工坊**：8 款车漆即时重涂 3D 车身，4 档底盘调校（均衡 / 弯道下压力 / 极速低阻 / 漂移设定）真实改变过弯、风阻与手刹起漂手感。
- **车手生涯与 12 项成就徽章**：记录累计里程、胜场、极速、最高连击漂移与赛道征服进度，达成成就实时弹出徽章提示。
- **每日挑战**：顶部一键进入今日随机组合（9 赛道 × 5 车型 × 7 玩法 × 4 天气），累计连续打卡天数。
- **幽灵车对比（G）**：在「个人计时」与「弯道练习」自动保存最佳圈幽灵车，左上角实时显示快慢秒差。
- **尾流与超车播报**：高速跟车吃尾流最高降阻 38%，并实时播报超越/被超越对手与名次。
- **个人计时奖牌**：按车型与赛程标定金、银、铜牌目标线。
- **全新赛道仪表 HUD & 手柄支持**：新增弧形速度环、实时 2D G 值球、高速/Boost 视觉速度线以及全功能标准游戏手柄支持。

| 手柄按键 | 功能 |
| --- | --- |
| 左摇杆 / 十字键左右 | 转向 |
| RT / LT | 油门 / 刹车（停稳后长按倒车） |
| A | 手刹 / 车库发车 / 确认弹窗 |
| B | 弹窗次要操作 |
| X / Y / RB | 一键 Boost / 切换视角 / 手动升降尾翼 |
| Start | 暂停 / 继续 |

**驾驶操作**　W / ↑ 加速，S / ↓ 刹车，停稳后继续按住 S / ↓ 即可倒车。A、D 或左右方向键转向，空格拉手刹，引擎盖和驾驶席视角挂入 R 挡时会显示倒车影像，C 切换四种视角，SU7 Max 可按 R 手动升降尾翼，个人计时与弯道练习可按 G 开关幽灵车，Esc 或 P 暂停；同时兼容标准手柄（RT/LT 油门刹车、左摇杆转向、A 手刹、X Boost、Y 视角、RB 尾翼、Start 暂停）。手机左手按住或滑动方向条，靠近中心微调、靠近两端打满、松开回正。右手同时控制踏板，停稳后继续按住「刹车」即可倒车。遇到明显弯道，前方提示会显示方向和距离。车库和暂停菜单可选流畅、均衡或高清画质，选择会自动保存。

**一键 Boost**　SU7 标准版、SU7 Max、SU7 Ultra 和 YU7 GT 在游戏里都可使用。键盘按 B，手机轻点油门上方的 BOOST，再给油即可加强中高速加速。单次最长 20 秒，再按一次可以提前结束。游戏采用 30 秒冷却，暂停会冻结计时。小米曾在[官方答网友问](https://weibo.com/ttarticle/p/show?id=2309405031537782685731)中介绍 SU7 Max 的 20 秒峰值扭矩输出。

车库记住上次选择的赛道、玩法、赛程和难度。赢下对抗赛、完成限时或测速目标，或在弯道走线中全数命中后，可在结算页直接挑战下一档。

下载 `index.html` 后可在支持 WebGL 的浏览器中离线打开。页面内嵌车模、线路和场景纹理。

安卓安装包也可离线游玩，支持 Android 9 及以上、OpenGL ES 3.0 和支持 WebGL 2 的系统 WebView。横向握持手机，用左手转向、右手控制踏板。轻点右上角切换尾翼或视角，切到后台会暂停。

## 本地构建

```sh
npm ci
npm run build
node --test
```

发布文件是根目录的 `index.html`。车模、环境和线路数据的来源见[素材署名](CREDITS.md)。

构建安卓包需 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。设置 `JAVA_HOME`、`ANDROID_HOME`、`NORDRUN_KEYSTORE` 和 `NORDRUN_KEY_PASSWORD`，使用别名为 `nordrun` 的签名密钥，在网页构建完成后执行 `python android/build.py Nordrun.apk`。

**发布应用内更新**　为新版本提高 `android/build.py` 中的 `versionCode` 和三段式 `versionName`，用原发布密钥签名。在本仓库创建标签为 `android-vX.Y.Z` 的 GitHub 正式发行版，附上 `Nordrun-X.Y.Z.apk` 并设为 Latest。发布说明会显示在玩家的更新窗口。可先在草稿中上传完整 APK，再公开发行版。
