# 北环竞速 · 小米车库

[打开游戏](https://cy642.github.io/su7-max-nordschleife/)

[下载安卓横屏版 APK](https://github.com/cy642/su7-max-nordschleife/releases/download/android-v1.5.0/Nordrun-1.5.0.apk)

在车库点车名或「换车」，可以选择 SU7 标准版、SU7 Max、YU7 GT、SU7 Ultra 或 Vision GT。车辆选择会保存在当前设备。历史版本的成绩保留在 SU7 Max 名下。车库点「看座舱」即可从驾驶席观察仪表和方向盘。

**选择赛道**　车库里先选赛道，再选玩法和赛程。路线图的橙色标记表示隧道。选择「弯道练习」能从指定路段直接出发。成绩按赛道、玩法和车型分别保存。

| 赛道 | 短程 / 全圈 | 沿途和练习起点 |
| --- | --- | --- |
| 纽博格林北环 | 3.2 / 20.832 km | 森林赛道，可从卡鲁塞尔或植物园起步。 |
| 独库雪山 | 3.2 / 7.2 km | 雪墙、垭口和两段穿山隧道。「雪廊穿山」从洞口前 110 米出发。[试玩](https://cy642.github.io/su7-max-nordschleife/?route=duku&event=practice) |
| 海底隧道 | 2.8 / 6.0 km | 从海岸向下驶入沉管，两段玻璃观景廊可以看见鱼群。「全景观景管」从第一段玻璃廊前 110 米出发。[试玩](https://cy642.github.io/su7-max-nordschleife/?route=subsea&event=practice) |
| 丹霞峡谷 | 3.0 / 6.4 km | 连续换向后驶入红砂岩壁，「石门穿峡」直接体验穿山路段。[试玩](https://cy642.github.io/su7-max-nordschleife/?route=canyon&event=practice) |
| 夜港高架 | 2.6 / 5.4 km | 港区下穿道、码头吊机与跨港斜拉桥，「高架引桥」可直接驶向主桥。[试玩](https://cy642.github.io/su7-max-nordschleife/?route=harbor) |

四条新赛道为原创闭环。独库雪山的雪墙、垭口和山地地貌参考了独库公路的公开资料。[新疆交通运输厅](https://jtyst.xinjiang.gov.cn/xjjtysj/zwgg/202505/1bc0833e1b754ae98576021d349ca627.shtml)

**线上试驾**　车库点击「线上试驾」，选择机场性能测试或公路自由试驾，再点击开始。机场用平直跑道测加速，冲过 400 米线后，在 600 米黄框内停稳。自由试驾使用所选赛道，可以无对手连续绕圈，在「试驾菜单」结束行程并查看报告。每个场地分别记录每款车的成绩，可比较零百加速、100–0 km/h 刹停距离和最高车速。试驾中可以切换视角、灯光和鸣笛，SU7 Max 还可以手动升降尾翼。

第一代 SU7 标准版采用后驱调校，Max 配电动尾翼。YU7 GT 的 SUV 车身与驾驶视点更高，Ultra 采用固定大尾翼和赛道套件。Vision GT 按小米展示的概念车单独建模，零百与极速使用游戏设定。车库量产车参数引用厂商资料，赛道成绩取决于驾驶操作和游戏物理。

| 玩法 | 怎么玩 |
| --- | --- |
| 六车竞速 | 和五辆同级对手跑短程或全圈。入门、运动、专家、大师四档会改变对手的刹车点、动力和弯中速度。 |
| 追击赛 | 单挑一辆提前占据赛道位置的对手。双方同时起步，领先冲线获胜。车库显示初始车距，比赛中实时显示追回或领先了多少米。 |
| 淘汰赛 | 六车起跑，在三分之一和三分之二赛程各淘汰最后两车，剩余两车冲线争冠。支持四档难度。 |
| 弯道走线 | 顺序挑战入弯、弯心、出弯三道门。对准黄门中心并达到提示速度，蓝门预告下一处。漏门或速度不足每门加 4 秒。短程 9 门，全圈按赛道长度设门，纽北全圈共 36 门。达到命中目标才能留下成绩。 |
| 限时闯关 | 在倒计时归零前过门补时。专家和大师的每段时间按车型和前方弯道分配。 |
| 测速挑战 | 在三道测速门测量通过速度，以三门平均速度挑战当前车型和难度的目标。 |
| 个人计时 | 独自在短程或全圈挑战个人最佳。途中显示与个人最佳的累计用时差，终点可查看三段各自的成绩。 |
| 弯道练习 | 各赛道均有三个练习路段，每段单独保存最佳用时，可以冲线后立即重试。 |

**驾驶操作**　W / ↑ 加速，S / ↓ 刹车，停稳后继续按住 S / ↓ 即可倒车。A、D 或左右方向键转向，空格拉手刹，引擎盖和驾驶席视角挂入 R 挡时会显示倒车影像，C 切换四种视角，SU7 Max 可按 R 手动升降尾翼，Esc 或 P 暂停。手机左手按住或滑动方向条，靠近中心微调、靠近两端打满、松开回正。右手同时控制踏板，停稳后继续按住「刹车」即可倒车。遇到明显弯道，前方提示会显示方向和距离。车库和暂停菜单可选流畅、均衡或高清画质，选择会自动保存。

**一键 Boost**　SU7 标准版、SU7 Max、SU7 Ultra 和 YU7 GT 在游戏里都可使用。键盘按 B，手机轻点油门上方的 BOOST，再给油即可加强中高速加速。单次最长 20 秒，再按一次可以提前结束。游戏采用 30 秒冷却，暂停会冻结计时。小米曾在[官方答网友问](https://weibo.com/ttarticle/p/show?id=2309405031537782685731)中介绍 SU7 Max 的 20 秒峰值扭矩输出。

车库记住上次选择的赛道、玩法、赛程和难度。赢下对抗赛、完成限时或测速目标，或在弯道走线中全数命中后，可在结算页直接挑战下一档。

下载 `index.html` 后可在支持 WebGL 的浏览器中离线打开。页面内嵌车模、线路和场景纹理。

安卓安装包也可离线游玩，支持 Android 9 及以上、OpenGL ES 3.0 和支持 WebGL 2 的系统 WebView。横向握持手机，用左手转向、右手控制踏板。轻点右上角切换尾翼或视角，切到后台会暂停。

## 本地构建

```sh
npm ci
npm run build
node --test
```

发布文件是根目录的 `index.html`。车模、环境和线路数据的来源见[素材署名](CREDITS.md)。

构建安卓包需 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。设置 `JAVA_HOME`、`ANDROID_HOME`、`NORDRUN_KEYSTORE` 和 `NORDRUN_KEY_PASSWORD`，使用别名为 `nordrun` 的签名密钥，在网页构建完成后执行 `python android/build.py Nordrun.apk`。
